# Admin.html 廃止完了記録

`Admin.html` は削除済み。`旧管理画面` サブメニューと `openAdminDialog` も削除済み。通常運用はWebモニター、設定シート、onOpenメニュー、各管理シートへ移行済み。

## 現在の役割

通常運用はWebモニター、設定シート、onOpenメニュー、各管理シートです。Webモニターの「管理操作」から目的別のシートへ直接移動できます。旧Admin.htmlは復活させません。

| 場面 | 操作 |
| --- | --- |
| 授業中の確認 | Webモニターの「更新」で前回から増えた解答を差分集計。表示件数・絞り込み条件を確認し、不要な条件は「絞り込みを解除」。 |
| 生徒を順にレビュー | 一覧から詳細レビューを開き「前の生徒」「次の生徒」で移動。開いたときの一覧順と正誤・レベル条件を維持。 |
| 準備・URL配付 | 「管理操作」でClassroom一覧・生徒名簿・トークン管理・配付ログへ移動。書込みや配付はリンク先のonOpenメニューで行う。 |
| 個別対応 | 詳細レビューの「この生徒の管理」から対象行を開き、氏名を確認して「④ 個別対応」を使う。 |
| 設定・テストプレイ | 「管理操作」から設定シートを開く。設定値や先生用のTEST_STUDENT_URLを確認する。 |
| 処理の失敗 | 「管理操作」から実行ログを開く。必要なら「⑨ 集計キャッシュを更新」で解答ログから正確に復旧する。 |
| 表示中一覧CSV | 現在の検索・絞り込み・並び順を使い、ブラウザ内で軽量な一覧CSVを作る。 |

## 更新と権限

Webモニターの更新操作は「更新」1つです。`refreshMonitorDashboard` が解答ログを500行ずつ差分集計し、途中結果をモニターキャッシュへJSONを分割保存します。画面は前回表示を保持し、更新中の進捗・失敗時の再試行を案内します。モニターキャッシュは直接編集しないでください。正本データは解答ログ・生徒名簿・トークン管理・配付ログです。

画面の自動更新は60秒ごとに同じ差分更新を呼びます。メニューの「⑤ 自動更新」は集計・モニターの全件更新を別実行する保守用で、通常は5分程度を推奨します。すぐ新しい解答を確認する場合はWebモニターの「更新」、全履歴から復旧する場合は「⑨ 集計キャッシュを更新」を使います。

表示・履歴参照は `refreshMonitorDashboard`、`getMonitorStudentAnswerReview`、`getCurrentMonitorStudentProblemTypeStats` を使います。管理ガイドの `getMonitorOperationLinks` は開いたときだけ管理者認証後にシートIDと対象行を読み、リンクだけを返します。個別URL・認証値・設定値・解答データは返しません。生徒の採点経路には追加しません。

Webモニターからトークン再発行、URL無効化、Classroom投稿削除、初期化、設定保存、同期対象保存を実行するAPIは呼びません。「管理操作」は操作場所への案内です。リンク先で氏名を確認したうえで既存メニューを実行してください。

表示モード・並び順・絞り込み条件は同じタブ内でブック別に復元します。検索文字列・氏名・認証値・履歴は保存しません。同名ClassroomはクラスIDで区別します。詳細レビューと管理操作は必要時に開くため、一覧に問題文や管理手順を並べません。

## 各管理シートで確認するもの

- `解答ログ`: 生徒ごとの解答、生徒回答、正誤、問題文、解説、所要時間
- `配付ログ`: URL配付、DRY_RUN、失敗、投稿削除結果
- `実行ログ`: トークン発行、配付、集計更新などの実行単位ログ
- `トークン管理`: 個別URL、最終アクセス日時、無効化状態、投稿削除指定
- `Classroom一覧`: 担当Classroom、同期対象
- `生徒名簿`: Classroom別の生徒情報
- `集計キャッシュ`: 生徒別の集計済み進捗
- `問題タイプ別キャッシュ`: 生徒・level・problemType別の成績
- `モニターキャッシュ`: Webモニター用の自動生成JSONスナップショット

## onOpenメニューへ移管済みの操作

- `⓪ 初期整備・保守` -> `⓪-1 管理シートを作成・補修`
- `⓪ 初期整備・保守` -> `⓪-2 管理データを全削除して初期状態に戻す`
- `① Classroom同期` -> `①-1 Classroom一覧を取得`
- `① Classroom同期` -> `①-2 同期対象の説明を表示`
- `① Classroom同期` -> `①-3 生徒名簿を取得`
- `② 生徒URL` -> `②-1 トークンを発行`
- `② 生徒URL` -> `②-2 配付対象を確認`
- `② 生徒URL` -> `②-3 DRY_RUNでURL配付確認`
- `② 生徒URL` -> `②-4 URLをClassroomに配付`
- `② 生徒URL` -> `②-5 失敗分を再送`
- `③ 投稿・URL取消` -> `③-1 投稿削除=1 のURLを無効化してClassroom投稿を削除`
- `④ 個別対応` -> `④-1 選択行の教師プレビューURLを表示`
- `④ 個別対応` -> `④-2 選択行のトークンを再発行`
- `④ 個別対応` -> `④-3 選択行のURLを無効化`
- `⑤ 自動更新` -> `⑤-1 集計・モニター自動更新を有効化`
- `⑤ 自動更新` -> `⑤-2 集計・モニター自動更新を停止`
- `⑤ 自動更新` -> `⑤-3 自動更新の状態を表示`
- `★ 先生用URLを設定シートに出力`
- `⑨ 集計キャッシュを更新`

## 設定シートへ移管済みの操作

次の設定は `設定` シートの `値` 列を直接編集する。

- `WEB_APP_URL`
- `POST_TEXT_TEMPLATE`
- `CLASSROOM_SEND_BATCH_SIZE`
- `DRY_RUN`
- `ENABLE_DISTRIBUTION_LOG`

旧出題設定7項目は現行版では除去済み。現在の10設定と53列の集計構造は[スプレッドシート構成](spreadsheet-schema.md)を参照する。

次のURLは `★ 先生用URLを設定シートに出力` で自動出力し、設定シートから開く。先生が直接編集する主設定としては扱わない。

- `MONITOR_URL`
- `TEST_STUDENT_URL`

## 移管済みの個別対応

| 項目 | 状態 | 移管先・運用 |
| --- | --- | --- |
| 個別トークン再発行 | 移管済み | `④ 個別対応` -> `④-2 選択行のトークンを再発行` |
| 個別トークン無効化 | 移管済み | `④ 個別対応` -> `④-3 選択行のURLを無効化` |
| 教師プレビュー | 移管済み | `④ 個別対応` -> `④-1 選択行の教師プレビューURLを表示` |
| 同期対象保存 | 移管済み | `Classroom一覧` シートの `同期対象` 列を直接編集する。 |
| 設定保存 | 移管済み | `設定` シートの `値` 列を直接編集する。 |

個別対応はClassroomへ自動投稿しない。個別再発行後の新URLはalertで確認し、必要に応じて先生が扱う。URL無効化はClassroom投稿自体を削除しないため、投稿も削除したい場合は `トークン管理` の `投稿削除` に `1` を入力して `③ 投稿・URL取消` を使う。

`TEST_STUDENT_URL` は `トークン管理` に作る先生用テスト生徒tokenであり、生徒名簿には追加しない。Classroom配付対象にも配付ログの通常 `SUCCESS` にも含めない。

## 残課題

解答ログ全履歴CSV、問題タイプ別詳細CSV、分析CSVは対象外。苦手傾向Classroom通知は今後の別機能として扱い、今回も自動通知は実装しない。本人向けの苦手チェックと管理者の問題タイプ別レビュー・変換確認スコアは実装済み。クラス全体の傾向や期間比較の分析は今後の課題。
