# Webモニターの一覧の表示項目設定

`表示項目を編集` で、詳細レビューを開かずに確認したい項目を一覧へ追加できます。

1. チェックで表示・非表示を選びます。番号・氏名は先頭に固定です。
2. ↑↓で選択した項目の順番を変更します。パソコンではドラッグも使えます。
3. `適用` で一覧へ反映して保存します。`キャンセル` またはEscなら変更を破棄します。
4. 元へ戻す場合は `標準に戻す` → `適用` を選びます。

標準・フォロー・詳細・配付確認の表示モードは維持しています。これらへ切り替えてもカスタムの列構成を保持し、`カスタム` へ戻せます。配付確認モードも番号・氏名を先頭にしています。項目の見出しを押すと生徒を並び替えられ、並び替え中の列を非表示にするとその並び替えを解除します。追加した時間・レベル別成績の未記録値は「—」と表示し、昇順・降順とも末尾に置きます。

## 追加できる指標

| 項目 | 表示内容・対象 |
| --- | --- |
| 累計正解数・全期間正答率 | 旧記録も含む全期間の正解数・正答率 |
| 平均解答時間 | 全期間・全レベルの有効な時間の平均と対象件数 |
| 正解時の平均解答時間 | 上記のうち正解した記録の平均と対象件数 |
| 直近10問の平均解答時間 | 最新10解答のうち有効な時間がある記録の平均と対象件数 |
| Lv.0〜8 正答率 | 現行カリキュラムの各レベルの正答率（正解数／解答数） |

時間は0.5秒未満・30分超・未記録を除外します。全期間の時間には旧記録も含みます。直近10問は「時間が有効な10件を遡って集める」という意味ではありません。途中で手を止めた時間も含むため、正答率や出題レベルとあわせて確認してください。件数を持たない既存キャッシュから表示した場合は、推測で件数を補わず時間だけを表示します。

61タイプの網羅状況や問題タイプごとの詳細は、引き続き詳細レビューで確認します。

## 保存とCSV

列構成と表示モードはブラウザー内にスプレッドシートごとに保存します。同じブラウザープロファイルを共有する場合は設定も共有されます。他の端末・ブラウザーには同期しません。ブラウザーの保存領域を消すと初期状態に戻ります。保存できない環境でもその画面での変更は適用し、保存できなかったことを表示します。

`表示中一覧CSV` は、検索・絞り込み・並び替え後の生徒と、表示中のデータ列の見出し・順番に一致します。履歴などの操作ボタン列は含みません。以前の固定列CSVから変わるため、別の表へ取り込む場合は見出しを確認してください。

列の編集・並び替え・CSV出力は取得済みの一覧データで処理し、追加のサーバー通信やスプレッドシートの書き込みを行いません。管理シート10個、設定10項目、集計53列は維持します。
