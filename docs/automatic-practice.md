# マニュアルとオートレベリング

生徒画面に「マニュアル」「オートレベリング」の二つの切替ボタンを常に表示する。マニュアルではLv.1〜Lv.6を自由に選び、Lv.1・Lv.3では変換も選べる。オートレベリングではGASが保存済みの正誤から次のレベル・変換・出題方向を選ぶ。生成AIは使わない。初期状態はマニュアル。切替時には問題を取り直し、モードとマニュアルの選択はブラウザに保存する。

## 調整ルール（ポリシーv1）

- 初めてのおまかせはLv.1のmol⇔質量から始める。調整の根拠はおまかせで解答した問題だけ。既存の手動練習の解答を自動進行の達成に読み替えない。
- Lv.1・Lv.3は一種類ずつ練習する。同じ段階の直近5問中4問以上正解し、往復の各方向を2問以上解いていたら次の種類へ進む。3種類が済むと次のレベルへ進む。
- Lv.2・Lv.4・Lv.5は、直近10問中8問以上正解し、そのレベルの6方向すべてを含む場合に次のレベルへ進む。Lv.6は上限として続けられる。問題数による強制終了はしない。
- 各段階で5問以上解き、直近3問すべてが数値の誤りだった場合に基礎練習を挟む。Lv.2→Lv.1、Lv.3→Lv.1、Lv.4→Lv.3、Lv.5→Lv.2、Lv.6→Lv.4。基礎練習の達成条件を満たしたら元のレベル・種類へ戻る。基礎練習中にさらに段階を下げない。
- 有効数字だけの誤りは、数値の誤りと区別する。計算レベルを下げず「最後に有効数字3桁を確認しよう」と表示する。
- 出題方向は練習回数の少ないものを優先する。解答時間・未解答は調整条件に使わない。

上記は調整可能な初期ルールであり、学力の確定診断ではない。実際の学習履歴を見て、昇格条件や基礎への戻し方を調整する。

## 保存と応答

正誤はサーバーに保存された元の問題で採点する。おまかせの段階情報も元の問題から解答ログのclientInfoへ記録し、ブラウザが送った段階・判定情報で上書きさせない。同じ解答の再送は一度だけ数える。以前の段階で出された未解答問題を後から送っても、新しい段階の進み具合には加算しない。

生徒別の集計キャッシュに進行状態を持ち、キャッシュが消えたら本人の解答ログから復元する。初回や消失時の復元はロック内で行う。恒久的な進み具合をブラウザや一時キャッシュだけに依存させない。

おまかせでは採点前の先読みを停止し、採点と集計の後に次の問題を作って同じ応答で返す。「次の問題」で追加通信を待たずに表示できる。通常の手動モードの先読みは継続する。

教師プレビューは解答を記録しないため、おまかせ切替を無効にして理由を表示する。先生の実操作検証には設定シートのTEST_STUDENT_URLを使う。

## 検証

全237テスト成功。70問を独立したGAS実行相当の環境で採点し、Lv.1→Lv.6の進行と上限を確認した。方向の偏りによる昇格防止、有効数字と数値誤りの区別、基礎練習からの復帰、再送、キャッシュ消失、手動解答・偽装された段階情報の除外も検証した。

390px幅の実ブラウザで、手動先読み中のモード変更、通信失敗後の再試行、採点後の次問表示、変換の切替、再読み込みでの再開、手動への復帰を確認した。GAS検証環境はdeployment version 12に更新した。


### GASでの実操作

検証用生徒でおまかせに切り替え、mol⇔質量の往復5問を正解した。64 g、2 mol、16 g、2 mol、18 gを入力して正解を確認し、次の問題がmol⇔個数へ切り替わった。通常の累積解答数は9→14として保持された。

採点と次問作成を含むgoogle.script.runの実測は3,349 / 3,272 / 3,147 / 3,790 / 2,699 ms。「次の問題」は返却済みの問題を表示する。これは単一ブラウザの検証であり、多人数同時利用の負荷試験ではない。

再読み込み後もおまかせ設定・累積14解答・mol⇔個数の段階を保持した。手動へ戻すとレベル選択が再表示され、おまかせへ戻しても進行を初期化しないことを確認した。


## モードの見つけやすさの改善（deployment version 13）

従来の「おまかせモード」チェックボックスを、常時表示する二つのモードボタンに変更した。オート中もマニュアルが使えることを明示する。オート側のカードには「現在のレベル」と「練習中の変換」を表示する。表示するレベルは現在の問題のレベルで、次の予定レベルや以前のマニュアル設定を表示しない。取得中はカードに「確認中…」を表示する。

マニュアルで選んだレベル・変換を保持し、オートから戻ったときに復元する。再読み込みを挟んでも維持する。オートの進み具合は従来どおりサーバーの解答履歴から復元する。教師プレビューではオートのみ無効で、マニュアルを利用できる。

全237テスト成功。390px幅の実ブラウザで、両モードボタンの表示、オートの現在レベル・変換表示、マニュアルLv.6→オートLv.1→再読み込み→マニュアルLv.6への復元を確認した。

GAS実画面でも二つのモードボタン、マニュアルの全6レベル、オートの現在Lv.1・mol⇔個数表示を確認した。マニュアルLv.3の選択とオートの進行は独立している。
