# マニュアルとオートレベリング（v4）

マニュアルはLv.0〜8を自由に選ぶ。Lv.0/1/3/5/8では練習種類も選べる。初期状態はマニュアルLv.0。選択は新版専用のブラウザー保存キーを使い、旧Lv.5/6の選択を読み替えない。

## オートの進行

新版の初回はLv.0の分子量・式量から開始する。Lv.1/3は種類別、Lv.5は密度基礎→mol→個数、Lv.8は有効数字の基本換算→総合。最後はLv.8総合を継続する。

段階内の出題種類数をNとして、直近max(5,2N)問の80%以上に正解し、全種類を各2問以上解くと次へ進む。1種類は5問、2種類は5問、6種類は12問、10種類は20問。問題の種類が多くても昇格不能にならない。少ない出題種類を優先する。

5問以上解答し直近3問が数値誤りなら、対応する基礎に戻る。Lv.1→0、Lv.2/3/6→1、Lv.4→3。Lv.5は密度基礎へ、Lv.7/8は問題に応じてLv.1/3/5へ。復習を達成すると元の段階へ戻る。復習中にさらに降格しない。有効数字だけの誤りでは降格せず、桁数を案内する。手動練習はオートの昇格に数えない。

## 保存と管理者表示

採点・カリキュラム版・段階情報は保存済み問題に基づいてサーバーが確定する。解答ログのclientInfoに保存し、再送は二重計上しない。古い段階で発行済みの問題は現在の進行に加算しない。CacheServiceが消えても本人のログから復元する。未公開の旧版ログは全期間の取組量として保持し、新版の進行には使わない。

管理者の標準・フォロー・詳細一覧とCSVに「オートの進行」を表示する。段階・練習種類・復習中と復帰予定レベル・直近解答が手動かを確認できる。保存済み解答から再構築した状態であり、生徒が今開いている画面のリアルタイム監視や学力の認定ではない。手動のみなら「オート未開始」。

オートは採点後の次問を同じ応答で返す。手動では解答中の先読みを維持する。教師プレビューは解答を保存しないためオートを無効化する。検証にはTEST_STUDENT_URLを使う。

## 検証

独立したGAS実行相当のランタイムで180問を採点しLv.0→8、再送、キャッシュ消失と復元を確認。種類の偏り・旧版ログ・偽装メタデータ・復習先カテゴリー・全件/差分集計の一致を検証する。モバイル幅で手動/オート、通信失敗の再試行、資料提示、密度の段階と有効数字を確認する。
