# v4.0.3 — オートレベリングを初期設定に

v4.0.2を基に、生徒がモードをまだ保存していないブラウザーではオートレベリングで開始するようにしました。解答に合わせて練習を調整し、自分でレベルや種類を選びたいときはいつでもマニュアルへ切り替えられます。

## 主な変更

- 初回のモードと読み込み前の表示をオートレベリングに変更しました。
- v4専用の保存キーで、保存済みのマニュアル・オートの選択と、手動のレベル・種類を引き継ぎます。保存済みのマニュアル設定を一律にオートへ変更しません。
- ブラウザー保存が利用できない場合や保存モードが不明な場合もオートで開始します。
- 教師プレビューは引き続きマニュアルのみ利用できます。

## 互換性と反映

Lv.0〜8、採点、オートの進行、教員モニターの表示項目設定、シート構成・解答ログの形式はv4.0.2から変更していません。オート未経験の生徒は従来どおりLv.0の分子量・式量から始まります。データ移行は不要です。

アプリ表示・npmのバージョンは `4.0.3`、Gitタグは `v4.0.3` です。GASのデプロイ番号は別の番号です。GASへの反映は別途必要で、このリリース作業では実験用・本番GASへ反映していません。

## 検証

`npm test` の全302テストが成功しました。初回、保存済みの両モード、不明な保存値、保存機能の利用不可、不正な手動選択データ、旧版の保存値の分離、教師プレビューの起動を実JavaScriptのブラウザーテストで確認しました。既存のLv.0〜8、モード切替・再読み込み・採点・振り返り・教員モニターの回帰テストも成功しています。GAS実画面と実際の生徒による利用は未確認です。
