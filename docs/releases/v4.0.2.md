# v4.0.2 — 教員モニターの表示項目を選択・並び替え

詳細レビューにある平均解答時間などを生徒一覧へ追加し、先生が確認したい項目と順番で表示できるようにした。

## 主な変更

- `表示項目を編集` で列の表示・非表示、↑↓とドラッグによる並び順変更、標準への復帰に対応。番号・氏名は先頭に固定する。
- 標準・フォロー・詳細・配付確認に加えてカスタム表示を用意。列構成と表示モードをブラウザー内にスプレッドシートごとに保存する。他の端末には同期しない。
- 平均解答時間、正解時・直近10問の平均解答時間、累計正解数、全期間正答率、Lv.0〜8それぞれの正答率（正解数／解答数）を選択可能にした。時間には有効な対象件数を併記する。
- CSVは表示中の生徒・データ列・順番で出力する。操作ボタン列を除き、画面の見出しと一致させる。

時間の除外条件や集計範囲は[一覧の表示項目設定](../monitor-column-settings.md)を参照。61タイプの網羅状況は詳細レビューに維持する。

## 更新・互換性

管理シート10個、設定10項目、集計53列、解答ログ24列を維持する。列設定用のシート追加・データ移行は不要。時間の件数は既存の差分集計状態から取り出し、件数がない既存キャッシュでは時間だけを表示する。列の編集やCSV出力で追加の通信・シート書き込みは行わない。生徒画面、採点、カリキュラム、オートレベリング、onOpenの動作は変更していない。

CSVは以前の固定列から選択した列へ変わる。取り込み先の表が固定の列順を前提としている場合は、必要な列を選び、出力見出しを確認する。配付確認モードの先頭は番号・氏名・Classroomの順になる。

GASへの反映は別途必要。ソースを反映してデプロイを更新した後、教員モニターを開き直して更新し、ブラウザー内保存の可否も確認する。実験用GAS・本番環境への反映は、このリリースの公開には含まない。

## 検証

`node --test` で全292テスト成功。新規テストでは列の選択・上下移動・ドラッグ、390px幅での操作、キャンセル・初期化、再読み込み後の保存、表示モード切替、スプレッドシートごとの保存分離、不正な保存値・保存失敗、未記録値の並び替え、CSVの列と絞り込み、列編集時に追加通信がないことを確認した。時間集計は0.5秒・30分の境界値、範囲外の除外、件数不明の既存集計も検証した。

ブラウザー操作はローカルのGAS API代替を使った検証であり、v4.0.2のGAS実機動作・通信時間の測定は未実施。
