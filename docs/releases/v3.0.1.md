# v3.0.1 — オートレベリングを初期設定に

生徒が練習を始めやすいように、モードをまだ保存していないブラウザではオートレベリングで開始します。解答に合わせてレベルと変換を調整し、自分でレベルを選びたいときはいつでもマニュアルへ切り替えられます。

## 変更内容

- 初回のモードと読み込み前の表示をオートレベリングに変更しました。
- 保存済みのマニュアル・オートの選択と、マニュアルのレベル・変換は引き継ぎます。既存生徒の保存済みマニュアル設定を一律にオートへ変更しません。
- ブラウザ保存が利用できない場合や保存モードが不明な場合もオートで開始します。
- 教師プレビューは引き続きマニュアルのみ利用できます。

オートの進行ルール、採点、解答ログの形式は変更していません。オート未経験の生徒は、従来どおりLv.1のmol⇔質量から始まります。

## 検証と反映

`npm test` の全273テストが成功しました。初回、保存済みの両モード、不明な保存値、保存機能の利用不可、不正な手動選択データ、教師プレビューの起動を実JavaScriptのブラウザテストで確認しました。既存のモード切替・再読み込み・採点・振り返りの回帰テストも成功しています。GAS実画面と実際の生徒による利用は未確認です。

アプリ表示・npmのバージョンは `3.0.1`、Gitタグは `v3.0.1` です。GitHubへのプッシュとGASのデプロイは別操作です。このリリース作業ではGASへ反映していません。
