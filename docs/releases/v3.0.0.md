# v3.0.0 — 学習・振り返り・教員管理の統合

Lv.1〜6のマニュアル練習とオートレベリングを整え、生徒の振り返りから教員の個別レビューまで対応したリリースです。

## 生徒の学習

- Lv.1〜6の出題構成を整理。マニュアルではレベル・変換を選択でき、オートでは学習状況に合わせて調整し、現在のレベルを表示します。
- 正解による進捗ゲージと、間違いの傾向・次の練習を確認する苦手チェックを追加しました。
- 採点後に結果・解説・次の問題へ進みやすくし、通信失敗や再送時の整合性を改善しました。

## 教員の確認と管理

- 更新ボタンを1つにまとめ、追加解答の差分集計と途中再開に対応しました。
- 問題・生徒の解答・正答・解説を必要なときに確認できる詳細レビューを追加しました。
- 正誤・レベルの条件を保って前後の生徒へ移動でき、一覧の条件復元・人数表示・絞り込み解除に対応しました。
- 管理操作ガイドから名簿・配付・設定・実行ログへ移動できます。個別レビューから対象生徒の管理行も開けます。

## 更新・運用

Classroomへの配付、URLの再発行・停止などの管理操作は、管理スプレッドシートとメニューから行います。v4以降のLv.0〜8構成・密度問題・新版の到達判定は、この版には含まれません。

アプリとnpmの版は `3.0.0`、Gitタグは `v3.0.0` です。GASのデプロイ番号は別の連番です。

採点・権限・保存・復旧・ブラウザ操作の自動テストと、push時のGitHub Actionsを整備しました。claspで検証用GASへ反映する前にも全テストを実行します。問題生成と採点を含む測定用データは通常の名簿・集計から分離しています。
