# v4.0.1 — 有効数字の表現・操作性・キャッシュ保存の改善

Lv.8の問題文を「有効数字3桁で求めてください」、解説を「有効数字3桁で求めます」へ変更。採点基準とカリキュラムは維持する。既存の保存済み問題文・解説は履歴として保持する。

## 主な変更

生徒画面は原子量資料を2列で表示し、選択肢が1つのLv.0カテゴリー欄を省く。出題時は問題文へ移動し、入力欄への自動フォーカスをなくした。通信失敗をURL不正と区別し、レベル・カテゴリーの取得に失敗したときは古い問題を採点できない状態にする。30秒の応答待ちで再試行へ戻し、遅延応答は画面に適用しない。保存後に次問の準備だけが失敗した場合も、保存済みの採点結果を返す。

クラス人数が多い場合の表示用JSONを既存モニターキャッシュ内で分割保存する。CacheService置換失敗時に古い表示を残さず、メニュー・自動更新の全件再集計後は差分集計状態もリセットする。管理シート10個、設定10項目、集計53列、解答ログ24列は維持し、onOpenはメニュー作成のみ。

## 更新・互換性

v4.0.0の学習履歴・オート進行を引き継ぐ。シートや列の追加は不要。ソースとスプレッドシートをバックアップして新版を反映し、「⑨ 集計キャッシュを更新」の後に教員モニターを更新する。表示用JSONは30,000文字以下に分割して一括保存し、欠損・重複・更新時刻の不一致があるデータは使用しない。詳細は[スプレッドシート構造](../spreadsheet-schema.md)を参照。

## 検証

検証: 全287テスト成功。390px幅でレベル・カテゴリー切替、通信失敗後の再試行、入力不正、資料11項目の保持、出題と採点を確認。資料欄の高さは同一Lv.8問題で約272pxから188pxになった。管理者は既存の更新・検索・絞込・詳細レビュー・CSV・管理操作を維持し、ボタン追加は行っていない。100人分の大きな表示用JSON、分割データの欠損、書込み失敗、大小更新、他のキャッシュ行保持、再集計後の差分表示を検証した。

指定の実験用GAS（デプロイ27）で、Lv.0オートのCaCO3に100、Lv.8のCH4 8 g→molに0.500を解答して、どちらも正解として保存した。問題文・解説の新表現、問題文へのフォーカス、次問・モード切替、Lv.0の単一選択欄非表示を実機確認した。管理者の⑨全件再集計と画面の更新も成功。
