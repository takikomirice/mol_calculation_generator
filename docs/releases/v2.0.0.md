# v2.0.0 - Fast student runtime and Web Monitor redesign

## Highlights
- 生徒画面を常時高速ルートに変更しました。
- 旧 `Admin.html` 管理画面を廃止し、スプレッドシートメニュー、設定シート、Webモニター中心の運用に移行しました。
- Webモニターをスナップショット表示中心に変更し、授業中の表示負荷を下げました。
- Webモニターから `モニターだけ更新`、`集計から完全更新`、管理スプレッドシートを開く、表示中一覧CSV出力ができるようになりました。
- 先生用URL出力時に、モニター表示用キャッシュをbest-effortで初期作成するようになりました。

## Student runtime
- 生徒APIは通常/高速切替なしで常時軽量ルートを使います。
- `STUDENT_FAST_MODE` 設定を廃止しました。
- 初回表示、問題取得、採点時に管理シート全体チェック、集計キャッシュ読み書き、問題タイプ別キャッシュ読み書き、解答ログ全読みを避けます。
- 採点レスポンスは正誤、正答、解説の返却を優先し、解答ログは正本データとして同期保存します。
- 採点レスポンスでは原則 `nextProblem` を同梱せず、クライアント側の次問プリフェッチを使います。

## Web Monitor
- Webモニターは通常、`モニターキャッシュ` の dashboard スナップショットを読みます。
- snapshot-missing 時に重いライブ構築を自動実行しません。
- `モニターだけ更新` は既存キャッシュからモニター表示用キャッシュだけを再生成します。
- `集計から完全更新` は解答ログから集計キャッシュ、問題タイプ別キャッシュ、モニターキャッシュを作り直します。
- 状態に応じて、次に押すべき更新ボタンを強調表示します。
- 表示中一覧CSVは、現在の検索・絞り込み・ソート後の一覧をブラウザ側で保存します。

## Operations
- `★ 先生用URLを設定シートに出力` で `MONITOR_URL` と `TEST_STUDENT_URL` を出力し、モニター表示用キャッシュも初期作成します。
- 初期作成に失敗してもURL出力自体は成功し、Webモニター側から更新できます。
- 集計反映は `⑨ 集計キャッシュを更新`、Webモニターの `集計から完全更新`、または `⑤ 自動更新` で整えます。
- Webモニターから実行できる書き込み系操作は `モニターだけ更新` と `集計から完全更新` のみに限定しています。

## Removed
- `Admin.html`
- legacy admin dialog entry point
- `STUDENT_FAST_MODE`
- `MONITOR_ALLOWED_EMAILS`

## Notes
- 既存スプレッドシートでは、アップデート後に `⓪-1 管理シートを作成・補修` を実行してください。
- `★ 先生用URLを設定シートに出力` を実行し、`MONITOR_URL` と `TEST_STUDENT_URL` を更新してください。
- 授業中に定期反映したい場合は `⑤ 自動更新` を有効化してください。
