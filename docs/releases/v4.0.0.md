# v4.0.0 — Lv.0〜8と現行スプレッドシート構成

計算練習をLv.0〜8へ再構成し、原子量からの分子量・式量計算、密度、資料選択、有効数字を段階的に学べるようにしました。新しいカリキュラムに合わせ、スプレッドシートの診断・補修と管理者の進行確認も整えています。

## 主な変更

| レベル | 練習内容 |
| --- | --- |
| Lv.0 | 与えられた化学式と原子量から分子量・式量を計算 |
| Lv.1 | molと質量・粒子数・標準状態の気体体積のうち1種類を往復換算 |
| Lv.2 | Lv.1の換算をランダムに出題 |
| Lv.3 | molを経由する物理量どうしの換算を1種類ずつ練習 |
| Lv.4 | Lv.3の換算をランダムに出題 |
| Lv.5 | 密度と質量・体積の計算から、mol・粒子数への換算へ進む |
| Lv.6 | 原子量表・アボガドロ定数・モル体積から必要な値を選んで基本換算 |
| Lv.7 | 密度を含む資料から必要な値を選ぶ総合計算 |
| Lv.8 | 有効数字3桁の基本換算から総合計算へ進む |

- モル質量の事前提示を原子量の提示へ変更しました。化学式は問題文で与え、式の導出は出題しません。
- 有効数字の厳密な採点はLv.8のみ。数値の誤りと桁数だけの違いを区別します。
- オートは新版のLv.0から開始し、出題種類の網羅と正答状況に応じて進行します。必要な基礎への復習と元の段階への復帰に対応しました。
- 教員の一覧・CSVに、保存済み解答に基づくオート段階、復習中の状態、復帰予定、直近の手動解答を表示します。生徒の画面をリアルタイム監視する機能ではありません。

## スプレッドシートと更新時の注意

管理シート10個・設定10項目・集計53列に整理しました。解答ログは24列を維持します。構成診断、不足項目の補修、重複検出、列順変更に対応し、使用しない旧設定・旧集計列を整理します。onOpenはメニュー作成のみで、シートを開くだけでは補修・集計・Classroom同期を実行しません。

**旧解答の履歴と正誤は保持しますが、新版のレベル別成績・苦手判定・オート進行には読み替えません。** 全期間の取組量には旧解答も含めます。詳細は[スプレッドシート構造](../spreadsheet-schema.md)と[オートレベリング](../automatic-practice.md)を参照してください。

更新は次の順で行います。

1. ソースとスプレッドシートをバックアップし、新版のGASソース・Webアプリを反映します。
2. スプレッドシートを開き直し、「⓪-1 管理シートを作成・補修」を実行します。
3. 「⑨ 集計キャッシュを更新」を実行し、教員モニターを更新します。
