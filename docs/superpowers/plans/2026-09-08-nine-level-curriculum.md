# Lv.0〜8 Implementation Plan

**Goal:** 合意済みのLv.0分子量・式量、Lv.1〜4換算、Lv.5密度、Lv.6〜7情報選択、Lv.8有効数字を実装する。

**Architecture:** Code.gsの既存出題・保存・集計を共通の現行カリキュラム定義で拡張。clientInfoにサーバーがカリキュラム識別子を記録し、保存済み旧解答は消さず現行到達判定から除外する。キャッシュは現行仕様で再構築する。

**Tech Stack:** GAS V8 / HTMLService / Sheets / node:test / Playwright

**Spec:** この会話で承認済みのLv.0〜8表。Lv.9は実装しない。全問題で化学式を与え、必要な原子量を提示。Lv.6〜8は固定原子量表と両定数、密度問題の資料を提示。有効数字の厳密判定はLv.8のみ。

## Steps
- [x] 出題・採点の回帰テストを追加して失敗を確認。分子量/式量は無単位、密度はg/mL（凝縮相）で、表示値から正答を独立検算する。
- [x] 現行レベル定義・原子量・密度問題・資料提示・解説をCode.gsに実装。Lv.5は密度単独→mol→粒子、Lv.8は基本→総合の順。
- [x] オートをLv.0開始〜Lv.8上限に変更。種類数に対応した判定窓と復習復帰を検証。旧メタデータ、再送、キャッシュ消失を検証する。
- [x] 生徒UI・苦手チェック・管理者UI/CSVを0〜8へ。保存済み回答に基づくオート段階と復習中状態を表示する。
- [x] 集計を9レベル＋オート進捗の現行スキーマへ。列順変更・非破壊補修・全件/増分集計の一致をテストする。
- [x] node --test、モバイル幅ブラウザ検証、自己レビュー。READMEと現行仕様資料を更新する。
- [x] 指定実験場をバックアップして4ファイル反映、シート補修・集計再構築、Lv.0/5/7/8の実機採点確認。Gitへの保存は現在のmainでコミットし、通常接続のプッシュを行う。
