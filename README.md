# モル計算ドリル Webアプリ

## アプリ概要

Google Apps Scriptで動く、Google Classroom連携型のモル計算ドリルです。教員が管理画面からClassroomの生徒名簿を取得し、生徒ごとの個別URLをClassroomのお知らせとして配付します。生徒は配付されたURLからドリルに取り組み、解答結果はスプレッドシートへ記録されます。

管理画面では、配付状況、解答ログ、生徒ごとの累計正答率、直近10問正答率を確認できます。

## ファイル構成

| ファイル | 用途 |
| --- | --- |
| `Code.gs` | Google Apps Script本体。管理シート作成、Classroom連携、トークン発行、URL配付、問題生成、採点、ログ記録を行います。 |
| `Student.html` | 生徒用画面。個別URLから開き、レベル選択、解答入力、正誤確認、直近10問正答率の確認を行います。 |
| `Admin.html` | 教員用管理画面。初期設定、Classroom取得、生徒名簿取得、トークン発行、URL配付、実施状況確認を行います。 |
| `appsscript.json` | Apps Scriptの設定ファイル。権限、Classroom API Advanced Service、Webアプリ設定を管理します。 |
| `tests/` | 開発用の自動テストです。Apps Scriptへ貼り付ける必要はありません。 |
| `pencil/` | 画面設計用ファイルです。Apps Scriptへ貼り付ける必要はありません。 |
| `運用手順.md` | 授業で使うときの詳しい手順書です。 |

## 初期設定

### 1. スプレッドシートを作成する

Google Driveで新しいスプレッドシートを作成します。授業用に使うファイル名を付けてください。

例: `モル計算ドリル_2026_化学基礎`

### 2. Apps Scriptを作成する

スプレッドシートで `拡張機能` -> `Apps Script` を開きます。

### 3. コードを貼り付ける

Apps Scriptエディタに、次のファイルを作成または上書きして貼り付けます。

| Apps Script側のファイル名 | このリポジトリのファイル |
| --- | --- |
| `Code.gs` | `Code.gs` |
| `Student.html` | `Student.html` |
| `Admin.html` | `Admin.html` |

### 4. appsscript.jsonを設定する

Apps Scriptエディタのプロジェクト設定で「`appsscript.json` マニフェスト ファイルをエディタで表示する」を有効にし、このリポジトリの `appsscript.json` の内容を貼り付けます。

主な設定内容は次のとおりです。

| 設定 | 内容 |
| --- | --- |
| 実行環境 | V8 |
| タイムゾーン | Asia/Tokyo |
| Classroom API | Advanced Serviceとして有効化 |
| Webアプリ実行権限 | 自分として実行 |
| Webアプリアクセス権限 | 学校の運用に合わせて設定 |

### 5. Classroom API Advanced Serviceを有効化する

Apps Scriptエディタで `サービス` から `Google Classroom API` を追加します。識別子は `Classroom` のままにします。

Classroomが取得できない場合は、Google Cloud側でClassroom APIが無効になっていることがあります。その場合は、Apps Scriptのプロジェクトに紐づくGoogle CloudプロジェクトでClassroom APIを有効化してください。

### 6. Webアプリをデプロイする

Apps Scriptエディタで `デプロイ` -> `新しいデプロイ` を選び、種類を `ウェブアプリ` にします。

| 項目 | 設定 |
| --- | --- |
| 実行するユーザー | 自分 |
| アクセスできるユーザー | 学校アカウントの範囲に合わせて設定 |

生徒がClassroomから開くため、アクセス権限は学校のGoogle Workspace設定に合わせます。校内アカウントだけで使う場合はドメイン内ユーザーに限定します。外部制限が必要な学校では、管理者のポリシーに従ってください。

デプロイ後に表示されるWebアプリURLを控えます。

### 7. 管理シートを初期化する

スプレッドシートに戻り、再読み込みします。メニューに `モル計算ドリル` が表示されたら、`管理シートを初期化` を実行します。

初回実行時は権限確認が表示されます。Classroom名簿取得、Classroomへのお知らせ投稿、スプレッドシートへの書き込みを許可してください。

### 8. 管理画面で基本設定を保存する

`モル計算ドリル` -> `管理画面を開く` を選びます。

初期設定で次の内容を確認・保存します。

| 項目 | 内容 |
| --- | --- |
| WebアプリURL | デプロイ後に控えたURL |
| 管理者トークン | 管理画面URLを保護するための文字列 |
| Classroom投稿文 | 生徒へ配付するお知らせ本文 |
| DRY_RUN | 本送信前の確認用。最初はON推奨 |
| 配付ログ | 通常はON |

## 管理画面の使い方

管理画面は、授業前に次の順番で使います。

1. `管理シートを初期化`
   スプレッドシートに必要な管理シートを作成します。既存データを残したまま列や書式を整えます。

2. `Classroom一覧取得`
   教員アカウントが担当しているClassroomを取得します。

3. `同期対象選択`
   今回使うClassroomだけを同期対象にします。対象外のClassroomはチェックを外します。

4. `生徒名簿取得`
   同期対象Classroomの生徒を取得し、`生徒名簿` シートへ反映します。

5. `トークン発行`
   生徒ごとの個別URLを作成します。URLは本人専用です。

6. `DRY_RUN`
   Classroomに投稿せず、配付対象とログだけを確認します。本送信前に必ず実行してください。

7. `URL配付`
   同期対象Classroomの生徒へ、Classroomのお知らせとして個別URLを配付します。

8. `実施状況確認`
   管理画面の集計、`解答ログ`、`配付ログ`、`実行ログ` を確認します。必要に応じて集計キャッシュを再作成します。

## 生徒画面の使い方

生徒には次のように案内してください。

1. Classroomのお知らせから、自分専用のURLを開く。
2. 名前が表示されていることを確認する。
3. `初級`、`中級`、`上級` からレベルを選ぶ。
4. 問題文を読み、数値だけを入力する。
5. `答える` を押して正誤と解説を確認する。
6. 続けて解く場合は次の問題へ進む。
7. 画面に表示される直近10問正答率を確認する。

URLは本人専用です。他の生徒と共有しないように伝えてください。

## 問題レベル

| レベル | 内容 |
| --- | --- |
| 初級 | `6.0×10^23` を使います。整数や扱いやすい数を中心に、基本的な mol、質量、粒子数、気体の体積の換算を練習します。 |
| 中級 | `6.0×10^23` を使います。有効数字2〜3桁程度の計算を含み、複数段階の換算も扱います。 |
| 上級 | `6.02×10^23` を使います。有効数字3桁、四捨五入を含む計算、原子1粒の質量や分子量・式量の推定を扱います。 |

## シート構成

| シート | 内容 |
| --- | --- |
| `設定` | WebアプリURL、投稿文、DRY_RUN、バッチサイズなどの設定を保存します。 |
| `Classroom一覧` | 担当Classroomの一覧と同期対象を管理します。 |
| `生徒名簿` | Classroomから取得した生徒情報を保存します。 |
| `トークン管理` | 生徒ごとの個別トークンと個別URLを管理します。 |
| `解答ログ` | 生徒の解答、正誤、問題、解説、所要時間を記録します。 |
| `配付ログ` | ClassroomへのURL配付結果を記録します。 |
| `集計キャッシュ` | 管理画面表示用の生徒別集計を保存します。 |
| `実行ログ` | トークン発行、配付、集計更新などの実行結果を記録します。 |

## 100人規模運用時の注意

- 授業前にトークン発行とURL配付を済ませてください。授業開始直後にClassroom送信を集中させない方が安定します。
- URL配付は必ず `DRY_RUN` で対象人数と内容を確認してから本送信してください。
- 解答ログ書き込みには `LockService` を使っています。同時アクセス時の重複書き込みや競合を抑えるためです。
- 同時送信が多い場合、Google側の一時的な制限で失敗する可能性があります。生徒画面には再送できるUIを用意しておき、失敗時は時間を置いて再実行してください。
- 配付ログで `ERROR` が残った場合は、失敗分だけ再送してください。

## トラブルシュート

### Classroomが出ない

- ログインしているGoogleアカウントが、対象Classroomの教師になっているか確認してください。
- Apps Scriptの `Google Classroom API` サービスが追加されているか確認してください。
- Google Cloud側でClassroom APIが有効になっているか確認してください。
- 初回認可でClassroom関連の権限を許可したか確認してください。

### 生徒名簿が取れない

- `Classroom一覧` で同期対象にチェックが入っているか確認してください。
- 対象Classroomに生徒が参加済みか確認してください。
- Classroomの名簿取得権限がある教員アカウントで実行してください。

### URL配付に失敗する

- まず `DRY_RUN` で配付対象が正しいか確認してください。
- `トークン管理` に `studentUrl` が作成されているか確認してください。
- Classroom APIの投稿権限が許可されているか確認してください。
- `配付ログ` の `errorMessage` を確認し、失敗分再送を実行してください。

### 生徒がアクセスできない

- Webアプリのアクセス権限が、生徒のGoogleアカウントで開ける設定になっているか確認してください。
- 生徒がClassroomで使っている学校アカウントでログインしているか確認してください。
- 古いデプロイURLを配付していないか確認してください。

### token不正と出る

- Classroomのお知らせにある本人専用URLを開いているか確認してください。
- `トークン管理` で該当生徒の `revoked` が有効になっていないか確認してください。
- トークンを再発行した場合は、新しいURLを再配付してください。

### 解答が記録されない

- `解答ログ` シートが存在するか確認してください。
- Apps Scriptのスプレッドシート書き込み権限が許可されているか確認してください。
- 生徒画面にエラーが出た場合は、時間を置いて再送してください。
- `実行ログ` やApps Scriptの実行ログでエラー内容を確認してください。

## 補足

- Webアプリは「自分として実行」するため、Classroomへの投稿やスプレッドシートへの記録はデプロイした教員アカウントの権限で行われます。
- 生徒ごとのURLにはトークンが含まれます。URLを知っている人がアクセスできる設定にする場合でも、トークン管理により本人用の画面として扱います。
- 運用の詳しい流れは `運用手順.md` を参照してください。
